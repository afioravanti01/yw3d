# yw3d
Yaml World in 3D

Mondo 3D a blocchi immerso nella natura, programmabile via YAML e codice, abitato da personaggi animati (guidati da script o da un modello AI) che rispettano la fisica del mondo.

È anche un **esperimento di Spec-Driven Development**: ogni fase ha una spec, un piano con i task e una retrospettiva con metriche, per capire se l'SDD scala su un progetto che cresce.
